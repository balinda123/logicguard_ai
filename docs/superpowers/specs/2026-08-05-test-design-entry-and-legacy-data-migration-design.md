# 测试设计入口与旧数据归档设计

## 目标

让用户进入“测试设计”后立即知道从哪里开始，并能在当前页面快速创建被测系统和首个环境。系统自动建立“试用期管理”及其测试环境，把既有试用期测试设计数据归入该系统，同时保持迁移可重复、可追溯且不静默丢失数据。

## 范围

- 优化“测试设计”的系统、环境和设计创建入口。
- 为管理员提供一步式“快速新建系统”弹窗。
- 新增原子创建“系统 + 首个环境”的后端命令。
- 建立或复用“试用期管理”系统，测试环境地址固定为 `https://onboardingtest.oa.wanmei.net`。
- 把旧“试用期转正系统”以及旧生成用例归入“试用期管理”。
- 同步 README、使用指南、开发文档、迁移文档和部署附录。

本次不新增预发或生产环境类型，不恢复已删除的旧测试设计页面、模板工作区或旧浏览器执行链。

## 用户流程

### 正常入口

1. 用户点击左侧“测试设计”。
2. 页面顶部显示系统和环境选择器。
3. 管理员可点击系统选择器旁的 `+` 打开“快速新建系统”弹窗；普通用户不显示该入口。
4. 弹窗一次填写系统名称、环境类型、环境名称和环境地址。
5. 点击“创建并使用”后，系统和环境在同一事务中创建，页面立即选中新范围。
6. 左侧使用带文字的“新建设计”按钮创建第一个设计单。
7. 设计单建立后进入“需求来源 → 生成用例 → 检查确认 → 回归执行”。

### 空状态

- 没有系统时：管理员看到“快速新建系统”，普通用户看到“请联系管理员配置系统和环境”。
- 有系统但没有启用环境时：提示管理员补充环境，普通用户看到不可执行原因。
- 有范围但没有设计时：显示“新建第一个测试设计”，不只显示无操作指向的空文案。

## 快速新建弹窗

字段：

- 系统名称：必填，默认可为空；从空状态进入时可预填“试用期管理”。
- 环境类型：只允许“本地启动”或“测试环境”。
- 环境名称：必填，测试类型默认“测试环境”，本地类型默认“本地启动”。
- 环境地址：必填，必须是合法 HTTP(S) 地址；localhost 允许 HTTP，远程地址要求 HTTPS。

提交期间禁用重复操作。成功后关闭弹窗并自动选中创建结果；失败时保留输入并显示后端错误。弹窗关闭后不产生任何半成品记录。

## 后端原子命令

新增单一 Tauri 命令创建系统和首个环境。命令只允许管理员调用，在 SQLite 事务中完成：

1. 校验系统名称、环境类型、名称和地址。
2. 创建系统。
3. 创建关联环境。
4. 返回系统与环境记录。
5. 任一步失败时回滚全部写入。

现有分别创建系统和环境的命令继续保留给“系统设置”完整管理界面使用。

## “试用期管理”种子与迁移

规范系统名称为“试用期管理”，规范测试环境原点为 `https://onboardingtest.oa.wanmei.net`。初始化和迁移必须幂等：

1. 若只有旧系统“试用期转正系统”，将其重命名为“试用期管理”，保留原 ID 和所有引用。
2. 若“试用期管理”已存在，直接复用，不创建重名系统。
3. 若新旧两个系统同时存在，将旧系统下的环境和测试设计归并到新系统；相同类型和规范化地址的环境复用目标环境。
4. 创建或复用测试环境“测试环境”，地址规范化为 `https://onboardingtest.oa.wanmei.net`。
5. 旧生成用例继续以“历史导入设计单 · 模块名”聚合，需求缺失时保留“历史导入数据（原始需求缺失）”版本。
6. localhost、`127.0.0.1` 和 `::1` 记录归到“试用期管理”的本地环境；测试域名记录及无 URL 的旧用例归到规范测试环境。
7. 无法安全归并或违反唯一约束的记录进入迁移隔离结果，不删除源记录。
8. 已有迁移标记不能阻止系统别名归并；结构归并与旧 localStorage 导入使用独立迁移版本。

测试设计的需求版本、生成批次、用例、审核记录和回归配置通过设计单关联，无需逐条改写下属表。所有直接保存 `system_id`、`environment_id` 的执行与测试资源必须在归并事务中保持引用一致。

## 前端组件边界

- `SystemEnvironmentPicker`：负责选择范围、展示快速创建入口和空状态，不直接维护完整系统列表表格。
- `QuickCreateSystemDialog`：独立管理弹窗字段、校验、提交和错误状态。
- `TestDesignPage`：接收创建结果，切换范围并刷新设计列表；将现有小型设计加号改为带文字的“新建设计”。
- `SystemEnvironmentManager`：继续承担系统设置中的完整管理，不与快速弹窗重复复杂功能。
- `testDesignBridge`：提供原子创建命令的强类型包装。

## 错误与权限

- 普通用户不能看到快速创建按钮，直接调用命令返回 `ADMIN_REQUIRED`。
- 重名系统、重名环境和非法地址返回可识别错误，不静默改名。
- 原子命令失败不刷新当前选择，也不留下只有系统没有环境的记录。
- 迁移失败保留原数据和可诊断结果；页面提示迁移隔离数量。
